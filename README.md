# منصة الأستاذ محمد عبد المقصود

## التشغيل على Windows

1. ثبّت Node.js 18 أو أحدث.
2. انسخ `env.example` إلى ملف باسم `.env`، ثم ضع كلمة مرور قوية للمعلم في `TEACHER_PASSWORD` (12 حرفاً على الأقل).
3. افتح PowerShell في مجلد المشروع وشغّل:

   ```powershell
   node server.js
   ```

4. افتح `http://localhost:3000` في المتصفح واترك نافذة الخادم مفتوحة.

لا تفتح `index.html` مباشرة ولا تستخدم Live Server؛ المنصة تحتاج خادم Node.js لواجهات API والملفات.

## البيانات والنسخ الاحتياطي

تُحفظ سجلات الطلاب والإعدادات في `data/db.json` والملفات المرفوعة في `data/uploads/`. احتفظ بنسخة احتياطية من مجلد `data`، ولا تشارك محتواه أو ملف `.env` علناً. ملفات البيانات المحلية مستثناة من Git عبر `.gitignore`.

الخادم يستخدم وحدات Node.js المدمجة ولا يحتاج إلى تثبيت حزم إضافية.

## النشر الدائم على Render

يوجد إعداد نشر في `render.yaml` يشغّل الواجهة وواجهات API على نفس النطاق، ويربط `DATA_DIR` بقرص دائم في `/var/data` حتى لا تضيع قاعدة البيانات والملفات عند إعادة التشغيل.

1. ارفع ملفات المشروع إلى مستودع GitHub خاص. لا ترفع `.env` أو مجلد `data`؛ ملف `.gitignore` يستثنيهما.
2. في Render اختر إنشاء Blueprint واربط المستودع. راجع الخطة والقرص الدائم والتكلفة قبل تأكيد الإنشاء؛ إعداد القرص الدائم يحتاج خطة مدفوعة.
3. أدخل `TEACHER_PASSWORD` كمتغير سري في Render، ثم نفّذ النشر.
4. بعد نجاح النشر افتح رابط Render. الواجهة ستتصل بالخادم على النطاق نفسه تلقائياً.
5. أضف الدومين من إعدادات الخدمة في Render بعد التأكد من عمل رابط الخدمة.

بعد فتح رابط المنصة المنشور عبر HTTPS، اضغط «تثبيت التطبيق» واتبع تعليمات المتصفح. على iPhone استخدم «مشاركة» ثم «إضافة إلى الشاشة الرئيسية». يحتاج التطبيق إلى اتصال بالإنترنت لاستخدام الحسابات والمحتوى.

النشر يبدأ بقاعدة بيانات فارغة على القرص الجديد. لا ترفع بيانات الطلاب الحالية إلى المستودع؛ نقلها إلى الخدمة يحتاج نسخاً احتياطياً ونقلاً آمناً منفصلاً.
